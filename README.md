# Orbi website

Static GitHub Pages website for the Orbi Android game.

## Public URLs

- Home: `https://orbi.obriystudio.app/`
- Privacy: `https://orbi.obriystudio.app/privacy-policy/`
- Terms: `https://orbi.obriystudio.app/terms-of-service/`
- Cookies: `https://orbi.obriystudio.app/cookies-policy/`
- Support: `https://orbi.obriystudio.app/support/`

## Release checklist

Before enabling advertising, purchases, accounts, cloud saves, or a new SDK:

1. Update the Privacy Policy and Terms.
2. Update Google Play Data Safety and App Content declarations.
3. Add consent and privacy controls required by the provider and target regions.
4. Verify that the public site, in-app disclosure, and repository documentation remain consistent.

The website intentionally has no analytics or optional cookies in the current release.
