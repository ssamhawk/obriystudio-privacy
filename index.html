Orbi Privacy Policy

Effective date: 2026-08-02

Current Release

Orbi is designed for the first Google Play release without active advertising SDKs, analytics SDKs, in-app purchase SDKs, game accounts, or a game backend server.

Data Stored Locally On Your Device

The current version may store the following information locally on your device so the game can work between sessions:

  • Player profile name entered in the game.
  • Game progress, unlocked maps, run history, contracts, rank, and rewards.
  • In-game balances such as gold and crystals.
  • Settings such as language, music volume, sound effects volume, and haptics.

This local information is not sent to us in the current release.

Data We Do Not Collect In The Current Release

In the current release, we do not operate a server that receives your gameplay profile or progress. We do not collect account registration data, email addresses, phone numbers, precise location, contacts, photos, or messages.

Local Data Deletion

Because the current release stores data locally on your device, you can remove local game data by uninstalling the app or clearing app storage in Android system settings.

Advertising, Analytics, And Purchases

The current release does not enable real-money purchases, rewarded ads, or advertising/analytics data collection. Future versions may add Google Play Billing, advertising, analytics, crash reporting, cloud saves, or account features. If that happens, this policy, the Google Play Data Safety form, and any required consent screens will be updated before those features are released.

Children

The current release is not intended to collect personal information from children. Before any advertising, analytics, account, or online feature is added, the target audience, content rating, and child-directed treatment requirements must be reviewed.

Third-Party SDKs

The current app build uses game/runtime dependencies needed to run the game UI and gameplay. Before enabling any SDK that sends data off the device, we maintain an SDK inventory and update the privacy disclosures.

Contact

Contact email for privacy requests: support@obriystudio.app
