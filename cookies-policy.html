Cookies Policy

Effective and last updated: August 17, 2026

Short version: The Orbi website currently does not set analytics, advertising, personalization, or consent cookies. We therefore do not display a cookie-consent banner.

1. About This Policy

This policy explains the use of cookies and similar browser technologies on orbi.obriystudio.app, operated by OBRIY STUDIO. A cookie is a small text file that a website may store in a browser. Similar technologies include local storage, pixels, and software development kits used for comparable purposes.

2. Current Website Configuration

The Orbi website is a static site. It currently:

  • does not use website analytics;
  • does not show advertising;
  • does not use marketing or personalization pixels;
  • does not create user accounts or login sessions;
  • does not set optional first-party cookies or browser storage.

Because no optional cookies are set by this website, there is currently nothing to accept or reject through a consent banner.

3. Hosting And Technical Requests

The website is hosted using GitHub Pages. GitHub may receive standard technical request information, such as IP address, browser type, requested page, date and time, and security logs, to deliver and protect the hosting service. This processing is controlled by GitHub and is described in the GitHub General Privacy Statement.

4. External Links

This site links to services such as Google, Firebase, GitHub, and email providers. Those services may use cookies after you follow a link. Their own cookie and privacy notices apply; OBRIY STUDIO does not control them.

5. The Orbi Game

Mobile-app identifiers and Firebase processing in the Orbi Game are not browser cookies. They are explained separately in the Orbi Privacy Policy.

6. Future Website Features

We may add website analytics, embedded media, support tools, or other features in the future. Before any optional cookie or similar technology is enabled, this policy will be updated and a consent control will be added where required by law. Optional technologies will not be treated as active merely because they are described as a possible future feature.

7. Contact

Questions about this policy may be sent to support@obriystudio.app.
